# What the schema leaves out

The schema leaves out the engine's computed columns, the CMMN and DMN models, and the rest of Fluxnova, such as the REST API and the web applications.[^about.md] The first release removed the old provenance overlay, the sixteen SSSOM sets and their overlay, and a MyBatis cross-check that counted no discrepancies by construction.[^changelog.md]
